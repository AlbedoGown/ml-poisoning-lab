# Диагностическая короткая серия

`short-run.json` — сохранённая серия с исправленной loss mask, но лишь 100 шагами
обучения: seed 42/43/44, старые диагностические test-шаблоны. Это **не финальная
оценка** и не часть сводки из `qwen-v3/`.

Чистый контроль в ней получился слабым. После этого выполнена калибровка на
validation с 1000 шагами и выделены новые финальные test-шаблоны и seed.
Метрики не смешиваются между протоколами.
