## CPU-классификатор

В каталоге `default/` сохранен локальный запуск версии 0.1.0 с параметрами по умолчанию: 2000 примеров, пять повторов, начальный seed 42, бюджеты 0%, 10%, 20%, 30%, 40%, 50% и 100%. Всего 35 обучений.

- [results.json](default/results.json): параметры, версии окружения, seed и отдельные измерения.
- [poisoning.png](default/poisoning.png): график среднего качества и стандартного отклонения.
- [report.html](default/report.html): автономный отчет. Скачайте через **Download raw file** и откройте в браузере.

Воспроизведение из корня проекта:

```bash
uv sync --locked
uv run --frozen ml-poisoning-lab --output results/reproduction
```

Небольшая случайная подмена в этой конфигурации почти не изменила среднее качество. Это наблюдение конкретного опыта, а не гарантия устойчивости к poisoning.

Для сравнения запусков используйте числовые поля JSON. Побайтовое совпадение PNG и HTML между версиями библиотек и платформами не гарантируется.
