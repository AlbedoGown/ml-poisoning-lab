# Демонстрационный запуск

Каталог `default/` содержит результаты реального локального запуска версии 0.1.0
с параметрами по умолчанию: 2000 примеров, 5 повторов, начальный seed 42,
бюджеты 0%, 10%, 20%, 30%, 40%, 50% и 100%. Всего 35 обучений.

Воспроизведение из корня проекта:

```bash
uv sync --locked
uv run --frozen ml-poisoning-lab --output results/reproduction
```

Сохранённые файлы:

- `default/results.json` — параметры, версии окружения, seed и индивидуальные измерения.
- `default/poisoning.png` — график среднего качества со стандартным отклонением.
- `default/report.html` — самостоятельный отчёт со встроенным графиком.

Для сравнения запусков используй числовые поля JSON; побайтовая идентичность
PNG/HTML между версиями библиотек и платформами не гарантируется.

Небольшая подмена в этой конфигурации почти не изменила среднее качество.
Это наблюдение конкретного эксперимента, а не гарантия устойчивости к poisoning:
атакующий здесь выбирает строки случайно и не оптимизирует атаку.
