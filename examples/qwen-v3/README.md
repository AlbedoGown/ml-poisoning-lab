# Финальный эксперимент с Qwen

Протокол `qwen_label_flip_v3`: Qwen3-0.6B, LoRA, 1000 шагов, seed 100/101/102.
180 обучающих заявок, 36 validation, 54 test. Подмена A→B у 54 строк train
(30% всего train, 90% класса A). Данные полностью синтетические.

| Seed | Чистая accuracy | Отравленная accuracy | A→B до | A→B после |
|---|---:|---:|---:|---:|
| 100 | 44,4% | 66,7% | 0% | 83,3% |
| 101 | 100% | 66,7% | 0% | 61,1% |
| 102 | 83,3% | 66,7% | 0% | 100% |

Средняя accuracy: 75,9% → 66,7%. Средняя доля A→B: 0% → 81,5%.
SD accuracy чистых адаптеров: 28,5 п.п.; это большой разброс, не доверительный интервал.
Test содержит только два сюжета на класс. Три повтора не являются тремя независимыми
выборками заявок. Защиты проверены в [отдельном эксперименте](../qwen-defenses-v1/README.md).

## Артефакты

- [report.html](report.html): самостоятельный HTML с графиком и таблицами, без сетевых ресурсов.
- [qwen-poisoning.png](qwen-poisoning.png): график среднего и выборочного SD.
- [results.json](results.json): все 378 ответов (54 исходной модели и 324 у адаптеров),
  метрики, история обучения, версии и параметры.
- [dataset.json](dataset.json): точные вымышленные обращения и метки до подмены.
- [plan.json](plan.json): план, сохраненный до первой оценки финального test.
- [model-manifest.json](model-manifest.json): SHA-256 исходных весов, независимо сверенный с именем Hub blob.
- [calibration.json](calibration.json): чистое обучение на seed 42 и оценка только на validation,
  использованные при выборе 1000 шагов.

Шесть финальных обучений заняли суммарно около 13 минут. MLX сообщил пиковое
потребление около 1,83 ГБ на этапе обучения; это показатель аллокатора MLX,
а не полная занятая память компьютера или RSS процесса.

## Воспроизведение

Из корня проекта на Mac с Apple Silicon:

```bash
uv sync --locked --extra qwen
uv run --frozen --extra qwen qwen-poisoning-lab --output artifacts/reproduction
uv run --frozen --extra qwen python -m ml_poisoning_lab.qwen.report artifacts/reproduction/results.json --output results/reproduction
```

Веса и адаптеры не включены в Git. После первой загрузки вычислительные этапы
работают с локальным снимком модели. Между платформами возможны численные различия.

Все итоговые accuracy и macro F1 независимо сверены со scikit-learn по сохраненным
ответам. Проверены хеши данных и исходников, число подмен и число обучаемых токенов.
На момент финальной серии прошли 70 тестов, включая интеграционный тест loss mask на MLX. После добавления защит набор был расширен; команды проверки есть в [главном README](../../README.md#проверка-кода).

HTML-отчет можно скачать через **Download raw file** и открыть в браузере. Для чтения на GitHub используйте таблицу выше и [статью](../../docs/article-qwen.md).
