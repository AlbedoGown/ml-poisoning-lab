# Подготовка статьи для Codeby

Рабочий заголовок: **Почему общей точности недостаточно при проверке отравления Qwen**.

- `article-qwen.md` — исходник текста для редакторских правок.
- `article-qwen.bbcode.txt` — тело статьи в BBCode, заголовок темы указывается отдельно.
- `../examples/qwen-v3/qwen-poisoning.png` — график для добавления как вложения.
- `../examples/qwen-defenses-v1/defenses.png` — второй график, проверка защит.
- `../examples/qwen-v3/results.json` — полные измерения для проверки цифр.
- `qwen-methodology.md` — подробности методики и история диагностических изменений.

BBCode подготовлен по [официальной справке Codeby](https://codeby.net/help/bb-codes/):
заголовки, таблицы, код и ссылки. При переносе график нужно загрузить как вложение
и вставить штатным редактором. Идентификатор вложения появится после загрузки;
выдуманного `[ATTACH]` в черновике нет.

Перед отправкой проверить предпросмотр таблиц и кода в редакторе Codeby.
Предпросмотр на самом форуме в рамках этой работы не выполнялся.

Репозиторий остаётся приватным. Для воспроизведения сторонним читателем нужно
отдельно решить, как предоставить исходники: открыть репозиторий либо подготовить
публикуемый архив. Черновик не обещает, что код уже публично доступен.

На Codeby ничего не отправлялось. Готовность статьи к размещению не означает
публикацию, изменение доступа к GitHub или отправку редакции.
